02 / LONG-TERM SCENARIOS

State grows.
Make the assumption visible.

HYPOTHETICAL · NOT A FORECAST

For an imagined state-growing app, compare a consumed-gas value proxy with the balance tied to retained state. Workload, retention and future static prices are assumptions; none are extrapolated from the 13-second header sample.

Retention is an idealized end-of-day model. Deletion gas, write-before-delete peaks, feasibility and full account charges are excluded. No values leave this browser.

CUMULATIVE CONSUMED-GAS VALUE PROXY—

Not upfront gas purchase, a total transaction bill or observed spending.

GROSS BALANCE · WITH RETENTION—

A balance tied to idealized additional state, not cumulative spending.

GROSS BALANCE · APPEND-ONLY—

The same declared workload with no state deletion.

Do not add these into a “total cost”. The gas proxy is a modeled cumulative flow; storage balance is a stock. No token price or investment return is calculated.

03 / QUESTION THE CLAIM

Useful evidence.
Deliberately limited.

This sample can support a narrow description of reported header fields. It cannot establish adoption, economic sustainability or future token value.

01

Keep the denominator visible

Gas ratios use fields carried by newly included chunk headers. Carried headers are excluded. Failed source verification or duplicate newly included chunks stops the build.

02

Keep the raw fields

Chunk balance_burnt and block total_supply are reported fields. No made-up issuance, annualization or revenue formula.

03

Make a claim falsifiable

If a broader, representative sample contradicts this snapshot, revise the claim. A reproducible small sample still has sampling limits.
